This note is a continuation of the JADE Note 103~\cite{JCN:103}
``A guide to resurrected JADE Data and Software'' and describes
the porting of JADE~\cite{Bartel:1986ua} software from the AIX platform to Linux
(as of 2016, 2022 and 2026).
The note has explicitly the same structure as the JADE Note 103~\cite{JCN:103} and describes only
the amendments to the software and data.
