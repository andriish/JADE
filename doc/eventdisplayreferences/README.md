Reference pictures of the historic JADE event display (the targets of the display
tests, see `doc/EventDisplay.md`):

* `2.jpg` (was `CCdat1_04_09.jpg`) - Monte Carlo event, R-phi section with detector hardware,
  lead glass energies, track and cluster header lines, orthogonal projections and
  the small dE/dx plot. `JADEZ_RPHI_1` tries to reproduce its layout.
* `1.jpg` (was `1004227_t.jpg`) - photograph of an early display.

Sources:

* `2.jpg` (was `CCdat1_04_09.jpg`) is the figure of the CERN Courier article "Study group considers how to preserve data"
  (29 April 2009, https://cerncourier.com/a/study-group-considers-how-to-preserve-data/), file
  `wp-content/uploads/2009/04/CCdat1_04_09.jpg` (the file is identical to ours). Caption: "A simulated event in the JADE detector,
  generated using a refined Monte Carlo program and reconstructed using revitalized software more than 10 years after the end of the
  experiment. Image credit: Siggi Bethke."
* `1.jpg` (was `1004227_t.jpg`): the source is not identified. The file name suggests the CERN Document Server record 1004227
  (https://cds.cern.ch/record/1004227), which could not be checked automatically (the server asks for a browser check).
